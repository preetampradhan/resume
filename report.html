1. ABOUT THE WEBSITE

This project is a personal resume and portfolio website presenting Preetamjeet Pradhan as a high-achieving undergraduate dual-degree student at NMIMS (B.Com Honours) and IIM Bangalore (BBA-Digital Business and Entrepreneurship, BBA-DB&E) seeking an internship in analysis and management. Built on a clean semantic HTML foundation styled with a sophisticated CSS design system, the site structures academic credentials, school leadership at SAI International School, competitive debate accomplishments, and key practical capabilities into an engaging, single-page scrollable experience optimized for recruiter review.

3. IMPROVEMENTS AND INTERACTIVE ELEMENTS

  • Sticky navigation & glassmorphism: A persistent navigation header with backdrop blur provides effortless in-page jumping across desktop and mobile devices.
  • Scroll progress indicator: A scroll-driven blue progress bar (using animation-timeline: scroll()) fills across the navbar as the reader moves down the page.
  • Hero stat grid & status pill: A 3-column CSS Grid highlights key metrics (95.8%, Leadership, Dual Degrees) paired with a pulsating green radar dot indicating availability.
  • Dedicated printable A4 sheet: Integrated @media print stylesheet isolates the resume on a clean single A4 page, automatically suppressing background colors, navbar, and footers.
  • Zero-dependency performance: Engineered using pure semantic HTML5 and vanilla CSS3 without heavy frameworks, guaranteeing sub-second load times and flawless GitHub Pages hosting.

4. TECHNICAL STRUCTURE

Area Implementation visible in the project repository
Frontend Semantic HTML5 markup with structured hierarchy (<header>, <nav>, <main>, <section>, <article>, <footer>), paired with Google Fonts (Fraunces and Figtree).
Build tooling Pure HTML5/CSS3 architecture without framework bloat, build steps, or external dependencies, ensuring instantaneous browser parsing and GitHub Pages compatibility.
Styling Modular CSS custom properties (:root variables) governing colors, typography, border radii, transitions, and layered shadow tokens.
Interaction CSS sticky positioning, modern CSS scroll-driven progress animation, smooth scroll behavior, card hover lifts, and radar pulse keyframe animations.
Layout system CSS Flexbox for navigation, button clusters, and header meta; CSS Grid for multi-column statistics and skills cards; clamp() for fluid typography.
Deployment Hosted publicly via GitHub Pages continuous deployment directly from the main branch of the GitHub repository.

5. COURSE CONCEPTS APPLIED

  • Semantic HTML structure: Clean document outline with proper headings, metadata tags, accessible labels (aria-label), and logical sectioning without unnecessary wrapper bloat.
  • Advanced CSS selectors & counters: Uses element, class, and ID selectors, pseudo-classes (:hover, :focus-visible), pseudo-elements (::before, ::after), and automated CSS counters (counter(sec, decimal-leading-zero)) to dynamically generate numbered section markers (01–04).
  • Full-width color bands: Leverages the box-shadow and clip-path: inset(0 -100vmax) technique to stretch background bands edge-to-edge while keeping page content centered inside a max-width container.
  • 5-tier responsive layout: Custom media queries tailored for extra-large monitors (1600px), desktops (1100px), tablets (860px), mobile phones (700px), small screens (380px), and landscape orientation with horizontal scroll navigation.
  • Accessibility & touch optimization: High contrast color ratios exceeding WCAG AA standards, visible keyboard focus indicators, touch targets meeting the 44px minimum height requirement, and prefers-reduced-motion compliance.

The project demonstrates how advanced CSS techniques—including CSS Grid, Flexbox, custom variables, scroll-driven timelines, and print stylesheets—can yield a polished, recruiter-grade web experience while preserving clean, semantic markup and lightweight performance.
